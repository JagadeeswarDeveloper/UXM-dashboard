# Dashboard UI Share

This branch contains the frontend UI files for three dashboards.

## Folder Structure

| Folder | Dashboard | Files |
|--------|-----------|-------|
| `ESG/` | ESG Dashboard | `esg_dashboard.html` |
| `UXM/` | UXM Dashboard | `uxm_dashboard.html` |
| `Agent-SLA/` | Agent SLA Dashboard | `agent_dashboard.html`, `agent_dashboard.css` |

## How to Run

Each dashboard is a standalone HTML file. Simply open the `.html` file in any modern browser — no build step or server required.
